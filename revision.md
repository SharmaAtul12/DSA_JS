## 📖 How This Log Works

Each day I revise a few previously-solved problems. Every revision gets logged in the table for its **topic** (same chapters as the [`README.md`](README.md)).

A revision means I **re-took the question** — read it fresh and solved it again. Each pass is recorded with its date:

| Column | Meaning |
| --- | --- |
| **Question** | Problem name (+ LeetCode ID) |
| **Description** | One-line reminder of the core idea / pattern |
| **1st Revision** | Date of the first re-take |
| **2nd Revision** | Date of the second re-take |
| **3rd Revision** | Date of the third re-take |

> `—` means that revision pass hasn't happened yet. Add new date columns (4th, 5th …) as the passes grow.
